# Design directory

This directory contains module specifications and, as the project matures, CAD source and exported geometry.

## Planned module folders

- `digit-wheel/` — ten-position wheel, detent, shaft interface.
- `carry-mechanism/` — carry trigger, transfer pawl, reset geometry.
- `accumulator/` — multi-digit frame and wheel stack.
- `repeat-counter/` — count register and mechanical stop.
- `crank-cycle/` — crank, cam, and home-position sequencing.
- `multiplier/` — integrated assembly.

A folder should include a README with revision, dimensions, material, print orientation, assembly, test procedure, and known limitations. Do not place untested STL files in a folder labeled release.
