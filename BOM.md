# Prototype bill of materials

This is a planning BOM. Quantities and exact fasteners will be finalized after the first CAD assembly.

| Item | Purpose | Status |
|---|---|---|
| PLA filament | Rigid geometry prototypes | Owned / available |
| PETG filament | Tougher functional-part experiments | Optional |
| TPU filament | Compliant/friction experiments | Optional |
| Smooth steel rod / precision shaft | Rotating axles | To select |
| M3 screws, nuts, washers | Modular assembly | To select |
| Small compression/torsion springs | Detent or pawl preload, if needed | To select |
| Calipers | Measure printed dimensions | Recommended |
| Deburring tool / files | Remove rough edges | Recommended |
| Dry lubricant compatible with plastics | Reduce friction where appropriate | Optional |

Avoid specifying magnets, bearings, or springs until the mechanism needs them. Minimize unique hardware to simplify assembly and sourcing.
