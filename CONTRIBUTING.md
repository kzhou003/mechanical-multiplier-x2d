# Contributing

Thanks for helping develop an open mechanical-computing project.

## Before submitting a design

- State which milestone and module the change supports.
- Include editable CAD source where possible.
- Include STEP and STL exports for released parts.
- Record units and revision identifiers.
- State material, printer, nozzle, slicer settings, and orientation.
- Include measured dimensions and fit results.
- Include a repeatable test procedure and observed cycle count.
- Identify known failure modes and limitations.

## Design status labels

- **planned** — concept only.
- **designed** — CAD exists, not printed.
- **printed** — physical part printed, not fully tested.
- **tested** — test procedure completed; report results.
- **released** — files, BOM, assembly instructions, and test evidence are available.

## Safety

Do not submit claims of load capacity, lifetime, or reliability without test evidence. Do not recommend powered operation for unvalidated mechanisms.
